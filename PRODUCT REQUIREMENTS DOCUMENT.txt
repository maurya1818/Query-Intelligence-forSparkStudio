PRODUCT REQUIREMENTS DOCUMENT

Project Name:
Query Intelligence API

--------------------------------------------------
1. OBJECTIVE
--------------------------------------------------

Build a backend API service that accepts natural language research queries, extracts structured intelligence using an LLM, stores the extracted data, and allows retrieval using a unique ID.

The project should demonstrate:
- API design
- LLM integration
- structured extraction
- backend engineering
- clean code organization

--------------------------------------------------
2. TECH STACK
--------------------------------------------------

Backend:
- FastAPI
- Python 3.11+

Database:
- SQLite

AI Model:
- DeepSeek V3 via OpenRouter API

Libraries:
- fastapi
- uvicorn
- sqlalchemy
- pydantic
- python-dotenv
- openai SDK

--------------------------------------------------
3. FUNCTIONAL REQUIREMENTS
--------------------------------------------------

3.1 CREATE QUERY ENDPOINT

Route:
POST /queries

Request Body:

{
  "query": "find battery technology startups in Southeast Asia"
}

Processing Steps:
1. Accept natural language query
2. Send query to DeepSeek V3 through OpenRouter
3. Extract structured information
4. Store:
   - original query
   - extracted structured data
   - timestamp
   - generated UUID
5. Return stored object

--------------------------------------------------
4. STRUCTURED EXTRACTION FIELDS
--------------------------------------------------

The LLM should attempt to extract:

- intent
- industry
- geography
- entity_type
- keywords
- filters
- summary

Example Output:

{
  "intent": "startup_search",
  "industry": "battery technology",
  "geography": "Southeast Asia",
  "entity_type": "startup",
  "keywords": [
    "battery",
    "technology",
    "startup"
  ],
  "filters": [],
  "summary": "Search for battery technology startups operating in Southeast Asia"
}

--------------------------------------------------
5. RESPONSE FORMAT
--------------------------------------------------

POST /queries Response:

{
  "id": "uuid",
  "query": "find battery technology startups in Southeast Asia",
  "structured_data": {
    "intent": "startup_search",
    "industry": "battery technology"
  },
  "created_at": "timestamp"
}

--------------------------------------------------
6. RETRIEVE QUERY ENDPOINT
--------------------------------------------------

Route:
GET /queries/{id}

Behavior:
Retrieve previously stored query and extracted intelligence using UUID.

Example Response:

{
  "id": "uuid",
  "query": "find battery technology startups in Southeast Asia",
  "structured_data": {},
  "created_at": "timestamp"
}
